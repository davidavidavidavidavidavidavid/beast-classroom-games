Bot difficulty
Each round, the active player (it alternates) picks a target number under 100. Then four ten-sided dice get rolled. Using all four rolled digits — each one exactly once, combined with +, −, ×, ÷, and parentheses — everyone builds their own expression to land as close to the target as possible. Whoever's expression is closest gets a point; if it's a tie, both players get a point. First to 5 points wins the match. The bot always computes correctly, but how hard it searches for a close expression changes with difficulty.
