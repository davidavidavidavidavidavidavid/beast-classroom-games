Ten multiplication facts, asked one at a time. Type the product and press Check. A wrong answer tells you the right one and moves on — nothing is retried mid-round, because the point is to see which facts are quick and which aren't. At the end you get your score and a list of any you missed, so you can run the same range again. This is a drill, not a strategy game — it exists so every fact can be asked directly, which the board games deliberately can't do.
